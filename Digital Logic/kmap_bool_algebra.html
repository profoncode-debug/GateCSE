Boolean Algebra and K Map

01

Introduction

Boolean algebra, also called switching algebra or binary algebra, works with just two values: 0 and 1.

  • Constants: 0 and 1.
  • Variables: Boolean (switching) variables can take either 0 or 1.
  • Binary operations: AND and OR (two inputs).
  • Unary operation: NOT (one input).

1.1 AND Gate

AND (logical product) is written as A · B or A ∧ B. Its output is 1 only when all inputs are 1; otherwise, it is 0. This applies to any number of inputs.

An AND gate is the digital circuit that performs this operation: Y = A · B.

1.2 OR Gate

OR (logical sum) is written as A + B or A ∨ B. Its output is 1 when at least one input is 1 (including when both are 1); it is 0 only when all inputs are 0. This applies to any number of inputs.

An OR gate is the digital circuit that performs this operation: Y = A + B.

1.3 NOT Gate (Inverter)

NOT (complement, negation, or inverse) flips a single input: 0 becomes 1, and 1 becomes 0. It is written as A′ or ~A.

A NOT gate, also called an inverter, performs this operation: Y = A′. Thus, 0′ = 1 and 1′ = 0.

1.4 NAND Gate

NAND = NOT of AND. Written as A ↑ B = (A · B)′, its output is 0 only when all inputs are 1; otherwise, it is 1. This applies to any number of inputs.

A NAND gate performs AND followed by inversion: Y = (A · B)′. The output bubble represents NOT.

1.5 XOR Gate (Exclusive OR)

XOR is written as A ⊕ B = A · B′ + A′ · B. For two inputs, its output is 1 when the inputs differ and 0 when they are equal.

For any number of inputs, XOR gives 1 when an odd number of inputs are 1, so it is called an odd parity function. For example, 1 ⊕ 1 ⊕ 1 = 1, while 1 ⊕ 1 ⊕ 0 = 0.

1.6 XNOR Gate (Exclusive NOR)

XNOR = NOT of XOR. It is written as A ⊙ B = (A ⊕ B)′ = A · B + A′ · B′.

For two inputs, its output is 1 when A = B and 0 when they differ. Hence, XNOR is also called the equivalence gate: A ⇔ B.

1.7 Number of Rows in a Truth Table

Each Boolean input has two possible values: 0 or 1. For n input variables, the number of possible input combinations is 2n.

Therefore, a complete truth table has 2n data rows, one for each combination. For example: 2 inputs → 4 rows; 3 inputs → 8 rows; 4 inputs → 16 rows.

1.8 Equivalence of Boolean Functions

Two Boolean functions are equivalent if they produce the same output for every possible input combination. Their truth-table outputs match, even if their expressions look different.

Example (De Morgan’s law): (X · Y)′ = X′ + Y′.

Algebraic Identities

2.1 Basic Identities

For any Boolean variable A ∈ {0, 1}, these identities hold. Here, + means OR and · means AND.

Basic Boolean algebra laws
LawORAND
DominationA + 1 = 1A · 0 = 0
IdentityA + 0 = AA · 1 = A
IdempotentA + A = AA · A = A

2.2 Complement Laws

  • (A′)′ = A — double negation restores the original value (involution).
  • A + A′ = 1
  • A · A′ = 0

2.3 Commutative Law

The order of inputs does not change the result.

  • A + B = B + A
  • A · B = B · A

2.4 Associative Law

Grouping does not matter when using the same operation.

  • (A + B) + C = A + (B + C)
  • (A · B) · C = A · (B · C)

2.5 Distributive Laws

  • A · (B + C) = A · B + A · C
  • A + (B · C) = (A + B) · (A + C)

2.6 Absorption Law

A absorbs an extra term containing A.

  • A + A · B = A
  • A · (A + B) = A

Example: A + A · B + A · B′ + A · C′ + A · D = A, by repeated absorption.

2.7 De Morgan’s Laws

To complement an expression, swap AND and OR and complement each input.

  • (A + B)′ = A′ · B′
  • (A · B)′ = A′ + B′

A literal is a single input variable or its complement, such as a, b′, or c. A product such as a′b is not a single literal; it contains two literals.

04

Complementing Boolean Expressions

The complement F′ reverses the output of F for every input combination. Use De Morgan’s laws for expressions built from AND, OR, NOT, and constants 0 and 1.

4.1 Procedure

  • Swap AND ↔ OR.
  • Swap 0 ↔ 1.
  • Complement each literal: X ↔ X′.
  • Preserve grouping; use parentheses to keep the original structure.

Apply De Morgan’s law through each level: (XY)′ = X′ + Y′ and (X + Y)′ = X′Y′. Remove double complements using (X′)′ = X.

4.2 Example 1

Given: F = AB′ + A′B

  1. Complement the sum: F′ = (AB′)′ · (A′B)′.
  2. Complement each product: F′ = (A′ + B)(A + B′).

This also simplifies to AB + A′B′ (XNOR), the complement of XOR.

4.3 Example 2

Given: F = (V′W + X)Y + Z′

  1. Complement the outer sum: F′ = [(V′W + X)Y]′ · Z.
  2. Complement the product: F′ = [(V′W + X)′ + Y′]Z.
  3. Complement the inner sum and product: F′ = [(V + W′)X′ + Y′]Z.

4.4 Example 3: Complement and Simplify

Given: F = (A + B′ + C)(A′ + B′)

  1. Complement the product: F′ = (A + B′ + C)′ + (A′ + B′)′.
  2. Apply De Morgan’s law: F′ = A′BC′ + AB.
  3. Factor B: F′ = B(A′C′ + A).
  4. Use A + A′C′ = A + C′: F′ = B(A + C′) = AB + BC′.

4.5 Can a Boolean Function Equal Its Complement?

No. For every input combination, F and F′ have opposite outputs: if F = 0, then F′ = 1, and vice versa. Therefore, F and F′ can never be equivalent.

Dual of a Boolean Function

For an expression built from AND, OR, NOT, and constants, its dual, written fd, is obtained by swapping AND with OR and 0 with 1. Variables and their complements stay unchanged.

5.1 Duality Rules

OR (+)AND (·)
01
10
A, B, A′, B′A, B, A′, B′ (unchanged)

Preserve grouping and all NOT operations. For example, (AB)′ becomes (A + B)′. Unlike complementation, forming the dual does not flip each literal.

5.2 Example 1

Given: f = B′ + C + A′(A′ + B′) + B(A′ + B′)

  1. Replace the outer ORs with ANDs.
  2. The term A′(A′ + B′) becomes A′ + A′B′.
  3. The term B(A′ + B′) becomes B + A′B′.

fd = B′C(A′ + A′B′)(B + A′B′) — the third option in the slide.

Using absorption, A′ + A′B′ = A′. Then B′(B + A′B′) = A′B′, so fd = A′B′C.

5.3 Dual of the Dual

Applying duality twice reverses every swap and restores the original function: (fd)d = f.

5.4 Example 2: Constants and Complements

Given: f = (a · 1)′ + (b′ + 0)′

  1. Swap AND/OR and 0/1, keeping each complement in place: fd = (a + 0)′ · (b′ · 1)′.
  2. Use a + 0 = a and b′ · 1 = b′: fd = a′ · (b′)′.
  3. Remove the double complement: fd = a′b — the fourth option in the slide.

5.5 Finding the Dual from a Truth Table

With inputs in standard binary order (000, 001, …, 111), complement the f column, then reverse that output column to obtain fd. Keep the input rows in their original order.

Rule: fd(x, y, z) = [f(x′, y′, z′)]′. Reversing the rows selects the complemented input combination; complementing its output gives the dual.

5.6 Practice: Equivalent Boolean Expressions

For Boolean inputs x and y, which expression is equivalent to (x && !y)?

&& means AND, || means OR, and ! means NOT.

  1. (!x || y)
  2. (!x && y)
  3. !(!x || y)
  4. !(!x && y)
  5. (x || !y)

Answer: C. By De Morgan’s law, (x′ + y)′ = x · y′, which is exactly x && !y.

06

Standard Forms of Boolean Expressions

6.1 Product and Sum Terms

A product term is the AND of one or more literals. A sum term is the OR of one or more literals. In either form, no variable appears more than once, whether complemented or uncomplemented.

Two-variable examples using both X and Y
Product terms (AND)Sum terms (OR)
X′ · Y′X′ + Y′
X′ · YX′ + Y
X · Y′X + Y′
X · YX + Y

A single literal, such as X′, qualifies as both a product term and a sum term.

Repeated variables: XXY′ simplifies to XY′ (XX = X), while XX′Y simplifies to 0 (XX′ = 0). The repeated-variable forms are not counted as valid product terms as written.

Watch the complement: X′Y′ and XY are product terms, but (XY)′ is not a product term as written: the complement covers a whole product, not a single variable. Similarly, (A + B)(C + D) is a product of sums, not an AND of literals.

6.2 Product Term Practice

Q1. Which options are product terms?

  1. AB
  2. A + B
  3. AB′C
  4. A′ + B′

Answer: A and C. Both are ANDs of literals with no repeated variable.

Q2. Which is a valid product term?

  1. A + B + C
  2. A · B′ · C
  3. A · B + C
  4. (A + B)(C + D)

Answer: B. The other options contain sums or compound factors.

Q3. Identify the product terms.

  1. A′B
  2. AB + AC
  3. A · (B + C)
  4. ABCD

Answer: A and D. B is a sum of products; C contains a sum as a factor.

6.3 Sum Term Practice

Q1. Which options are sum terms?

  1. A + B
  2. AB
  3. A′ + B
  4. A′B + AB′

Answer: A and C. Both are ORs of literals; B and D contain products.

Q2. Identify the sum terms.

  1. A + B + C
  2. AB + C
  3. A + B′
  4. ABC

Answer: A and C. Each summand must be a literal; AB is not a literal.

Q3. Identify the sum terms.

  1. A′ + B′ + C
  2. (A + B)(C + D)
  3. A + B + CD
  4. A + B + C + D

Answer: A and D. B is a product of sums, while C includes the product CD as a summand.

6.4 SOP (Sum of Products)

An SOP expression is the logical OR of product terms: P1 + P2 + P3 + …. Each product term is an AND of literals.

Example: A′BCD′ + AB′D + CD′ + AD′

A single literal is also a product term, so A + B + C is SOP. Product terms need not contain every variable.

Q1. Which expressions are in SOP form?

  1. AB + A′C
  2. (A + B)(C + D)
  3. A + B + C
  4. A′B + BC + AB′C

Answer: A, C, and D. Each is an OR of product terms. B is a product of sums.

Q2. Identify the SOP expressions.

  1. AB + A + BC
  2. A(B + C)
  3. (A + B)(C + D)
  4. A′B′ + ABC + B′C

Answer: A and D. A includes the single-literal product term A. B is not SOP as written, but expands to AB + AC; C is a product of sums.

6.5 POS (Product of Sums)

A POS expression is the logical AND of sum terms: (S1) · (S2) · (S3) · …. Each sum term is an OR of literals.

Example: (A′ + B + C + D′)(A + B′ + D)(C + D′)(A + D′)

Sum terms need not contain every variable. A single sum term also qualifies as POS.

Q1. Which expressions are in POS form?

  1. (A + B)(C + D)
  2. AB + CD
  3. (A + B + C)(A′ + B′)
  4. A + B + C

Answer: A, C, and D. A and C are ANDs of sum terms; D is a single sum term. B is a sum of products.

Q2. Identify the POS expressions.

  1. (A + B)(A′ + C)
  2. A + BC
  3. (A + B + C)(D + E + F)

Answer: A and C. B is not POS as written, but can be converted to (A + B)(A + C).

Both SOP and POS: f(a, b, c) = a + b + c is SOP as (a) + (b) + (c), an OR of single-literal product terms, and POS as (a + b + c), one sum term.

6.7 Notes: Single-Term Forms

  • A single sum term is both SOP and POS. Example: A + B + C is an OR of single-literal product terms (SOP), and one sum term (POS).
  • A single product term is both SOP and POS. Example: ABC′ is one product term (SOP), and (A)(B)(C′) is an AND of single-literal sum terms (POS).

6.11 Finding Maxterms from a Truth Table

Every input row corresponds to one unique maxterm, and every maxterm corresponds to one unique row. That maxterm equals 0 on that row only.

Rule: input 0 → uncomplemented variable; input 1 → complemented variable. OR the resulting literals.

Example: row 101 gives minterm xy′z and maxterm x′ + y + z′.

Maxterms and Minterms of a Function

7.1 Meaning and Terminology

For n variables, each row has a minterm mi and a maxterm Mi, with 0 ≤ i < 2n.

  • 1-minterms (true minterms): minterms corresponding to rows where F = 1. These are usually called the minterms of F.
  • 0-minterms (false minterms): minterms corresponding to rows where F = 0.
  • 0-maxterms (false maxterms): maxterms corresponding to rows where F = 0. These are usually called the maxterms of F.
  • 1-maxterms (true maxterms): maxterms corresponding to rows where F = 1.

Here, “true” or “false” describes the function output on the associated row. Every mi itself equals 1 on row i, and every Mi equals 0 on row i.

Remember: use the 1-rows for the function’s minterms and the 0-rows for its maxterms.

7.5 Canonical SOP/POS vs General SOP/POS

Every canonical SOP is SOP, and every canonical POS is POS. The reverse need not hold: canonical forms require every term to contain every variable exactly once.

Canonical forms are special cases of general forms
FormStructureUnique?
CSOPSum of minterms (minterm expansion)Yes
CPOSProduct of maxterms (maxterm expansion)Yes
General SOPSum of product terms; variables may be omittedNot in general
General POSProduct of sum terms; variables may be omittedNot in general

Uniqueness assumes a fixed variable set and order, with each selected minterm or maxterm listed once. Reordering terms does not produce a different canonical expansion.

Example: f(A, B) = A. Its CSOP is AB′ + AB, and its CPOS is (A + B)(A + B′). General forms can differ: A and A + AB are equivalent SOP expressions; A and A(A + B) are equivalent POS expressions.

08

Kmap Introduction

A Karnaugh map (K-map) is a graphical arrangement of a truth table used to simplify Boolean functions. It helps obtain a minimum SOP (mSOP) or minimum POS (mPOS) expression.

8.1 Minimum Forms

  • mSOP: an equivalent SOP with the fewest product terms and, among those, the fewest total literals.
  • mPOS: an equivalent POS with the fewest sum terms and, among those, the fewest total literals.

A minimum form is not necessarily unique. A function may have different minimum expressions with the same number of terms and literals. Its canonical expansion remains unique for a fixed variable set and order.

8.2 Cells and Adjacency

Each cell represents one truth-table row; n variables give 2n cells. Enter the function’s output for that input combination in the corresponding cell.

Adjacent cells differ in exactly one input variable. Horizontal and vertical neighbors are adjacent, including across opposite edges; diagonal neighbors are not.

Two-variable layout: columns a, rows b (labels show ab)
b \ a01

The labels above identify input combinations, not output values. For example, 00 and 10 differ only in a; 00 and 01 differ only in b.

Cube in Kmap

9.1 Finding mSOP Using a K-Map

  1. No zeros: groups must not contain any 0-cell.
  2. No diagonals: group horizontally or vertically adjacent cells.
  3. Power-of-two sizes: use rectangular groups of 1, 2, 4, 8, … cells.
  4. Make groups as large as possible to eliminate more literals.
  5. Cover every 1 with at least one group.
  6. Overlapping is allowed: a cell may belong to multiple groups.
  7. Wraparound is allowed: groups may cross opposite edges.
  8. Use the fewest groups needed to cover all 1s; among such covers, choose the fewest total literals.

Each selected group contributes one product term to the final SOP expression.

9.2 Valid Two-Variable Groupings

Columns are x1 and rows are x2. Red outlines mark groups of 1s. Keep variables that stay fixed; remove variables that change. A fixed 0 gives a complemented literal; a fixed 1 gives an uncomplemented literal.

Single-cell groups: two literals remain

Two-cell groups: one literal remains

Four-cell group: no literals remain

Both inputs vary across the whole map, so they are eliminated. The result is the constant function 1.

9.3 Steps to Find mSOP Using a K-Map

  1. Draw the map for the number of variables and label the axes in Gray-code order.
  2. Enter 1 in the listed minterm cells; the remaining cells are 0 (they may be left blank while working).
  3. Cover all 1s using the fewest valid cubes, making groups as large as possible. Include no 0s; overlap and wraparound are allowed.
  4. For each group, keep only fixed variables: use the complemented literal for fixed 0 and the uncomplemented literal for fixed 1.
  5. OR the group terms. Among covers with the fewest terms, choose the fewest total literals.

9.6 POS: Writing Sum Terms from Groups of 0s

For POS, group the 0-cells. Each group gives one sum term; AND the selected sum terms to obtain the expression.

  1. Eliminate variables that change within the group.
  2. Keep only variables that remain fixed in every cell.
  3. For a fixed 0, write the variable uncomplemented; for a fixed 1, write it complemented.
  4. OR the remaining literals to form the group’s sum term.

Group size: in an n-variable map, a valid cube of 2m cells eliminates m variables, leaving n − m literals in its term.

For minimum POS, cover every 0 using the fewest valid groups, then minimize total literals. Groups contain no 1s; use power-of-two rectangles, with overlap and wraparound allowed.

Implicant

11.1 Implicant of a Boolean Function

An implicant is a product term that guarantees F = 1 whenever that term is 1. On a K-map, it corresponds to any valid cube of 1, 2, 4, 8, … cells, including a single 1. It must contain no 0-cells.

Groups may overlap or wrap across edges. They do not have to be the largest possible groups to qualify as implicants. A group of 2m cells in an n-variable map produces a term with n − m literals.

Don’t-care convention in these slides: treat X cells as 1 when enumerating allowable cubes, including cubes made entirely of Xs. Such X-only cubes do not cover any required 1 and are unnecessary when selecting an SOP cover.

Prime Implicant

12.1 Definition

A prime implicant (PI) is an implicant that is not fully contained in any larger valid implicant. On a K-map, its cube cannot be enlarged without including a 0.

In simple words, make each cube as large as it can be. This means maximal by containment, not necessarily the largest cube anywhere on the map: prime implicants can have different sizes.

Every PI is an implicant; every implicant need not be prime. A smaller cube inside a larger valid cube is an implicant but not a PI.

For the slide’s enumeration, treat don’t-cares (X) as 1. As in topic 11, this may count maximal X-only cubes; they do not help cover required 1s.

Essential Prime Implicant

13.1 Definition and Role in mSOP

An essential prime implicant (EPI) is a PI that covers at least one required 1 not covered by any other PI. That uniquely covered 1 makes the PI compulsory.

  • Find all PIs, then check which required 1s have only one covering PI.
  • A PI containing only don’t-cares is not an EPI: Xs need not be covered.
  • Every EPI must appear in every minimum SOP.
  • If the EPIs together cover all required 1s, their sum gives the unique mSOP (ignoring term order).

If some 1s remain uncovered, select additional PIs to complete a minimum cover. A function may have no EPIs and still have a valid mSOP.
