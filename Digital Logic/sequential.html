Sequential Circuits

01

Introduction to Sequential Circuits

The key difference between combinational and sequential circuits is memory: whether past input history can affect the present output.

1.1 Combinational Circuits

  • The output depends only on the present inputs.
  • There is no memory, so past input values do not determine the output.
  • There is no feedback loop in the combinational circuit model.

Output = function of present inputs. The output responds after the circuit’s propagation delay.

1.2 Sequential Circuits

  • The output depends on the present inputs and the past history (sequence) of inputs.
  • Memory elements retain information about this history as the circuit’s stored state.
  • The stored state is fed back to the combinational circuit, allowing past activity to influence future behavior.

Output = function of present inputs and stored state. The same present inputs can give different outputs when the stored state differs.

Combinational vs Sequential Circuits
PropertyCombinationalSequential
Output depends onPresent inputs onlyPresent inputs and stored state
MemoryAbsentPresent
Past input historyDoes not affect the outputCan affect the output through stored state
FeedbackNo feedback loopStored state is fed back to the logic

1.3 Block Diagram of a Sequential Circuit

A sequential circuit consists of combinational logic and memory elements connected through feedback.

  1. Present inputs enter the combinational circuit.
  2. The combinational circuit uses the present inputs and the stored state to generate outputs and the information sent to memory.
  3. Memory elements store state information and feed it back to the combinational circuit.

Remember: combinational circuits have no memory; sequential circuits retain history through their stored state.

02

One-Bit Storage Device (Basic Idea)

Connect two NOT gates (inverters) in a loop, feeding the output of the second inverter back to the input of the first. This circuit has two stable logic states: Q = 0 and Q = 1.

Each inverter complements its input. After two inversions, the original value is restored, so the feedback supports the stored value.

2.1 Storing 0

Stored bit: Q = 0. Once established, this state can persist indefinitely in the ideal model while power is maintained.

2.2 Storing 1

Stored bit: Q = 1. The same circuit can retain 1 instead of 0; the stored value depends on which stable state has been established.

2.3 Why It Stores One Bit

Two stable states of the feedback loop
First inverter inputFirst inverter outputSecond inverter output QBit stored
0100
1011
  • Two stable states → one bit of information. A circuit with two stable states is called bistable.
  • Feedback maintains the state: two successive inversions return the same logic value.
  • This is the basic storage idea. Additional control circuitry is needed to deliberately write or change the stored bit; this bare loop does not provide a write input.

Remember: the loop can hold either 0 or 1. It does not guarantee a particular value at power-up.

03

SR Latch

3.1 Basic Idea and Types

An SR (Set–Reset) latch stores one bit using two cross-coupled gates. Unlike the bare inverter loop, it provides user inputs to control the stored value.

  • NOR implementation: active-high S and R inputs; called an SR latch.
  • NAND implementation: active-low S̅ and R̅ inputs; also called an S̅R̅ latch.

3.2 Digital Logic Terminology

Set → 1; Reset → 0; Retain → no change.

For the slide’s arrangement, the right output is Q (stored bit), and the left output is labelled Q̅. Input A = S sets Q; input B = R resets Q.

Gate equations: Q̅ = (S + Q)′; Q = (R + Q̅)′.
The two outputs are complements during valid operation.

Remember: 00 → hold; 10 → set; 01 → reset; 11 → forbidden. This table applies to the NOR implementation.

3.4 Set and Retain: Storing 1

Apply S = 1, R = 0 to set the NOR latch. Then return S to 0, giving S = R = 0. The feedback keeps the stored bit at 1.

Step 1 — Apply the set input (S = 1, R = 0). The 1 at S forces the first NOR output Q̅ to 0. The second NOR now receives two zeros, so Q becomes 1 after propagation through the gates.

Step 2 — Release S (S = R = 0). Q = 1 feeds back into the first gate, keeping Q̅ at 0. That 0 keeps the second gate output Q at 1. The set input is no longer needed to maintain the bit.

Set the latch, then remove the set input
Time stepSRQQ̅Operation
t = 01010Set
t = 10010Retain 1
  • During set: S = 1 forces Q̅ = (1 + Q)′ = 0. With R = 0, Q = (0 + 0)′ = 1.
  • During retain: the feedback Q = 1 keeps Q̅ = (0 + 1)′ = 0, which keeps Q = (0 + 0)′ = 1.

S = R = 0 is the retaining input combination. It preserves the previously stored bit; it does not force Q to 0.

3.5 Reset, Retain, Set, Retain

The following sequence shows that the same inputs, S = R = 0, can retain either 0 or 1, depending on the previous state. Each row shows the outputs after the latch has settled.

Reset, step 1 — Apply S = 0, R = 1. R directly forces the second NOR output Q to 0. With S = 0 and feedback Q = 0, the first NOR produces Q̅ = 1.

Reset, step 2 — Release R (S = R = 0). Q̅ = 1 keeps Q at 0 through the second gate. Feedback Q = 0 keeps Q̅ at 1 through the first gate, so the reset state persists.

Memory comes from feedback: after the set or reset input is removed, the latch retains the established state while power is maintained. These time steps label input changes; this basic SR latch does not require a clock.

3.6 Forbidden Input: What Happens During 11 → 00?

For this active-high NOR SR latch, the input pair is written in the order SR, and the output pair in the order QQ̅. Keep these two pairs distinct throughout the analysis.

  • GS: the NOR gate receiving S; its output is Q̅.
  • GR: the NOR gate receiving R; its output is Q.
  • dS, dR: propagation delays of GS and GR, respectively. A gate’s output takes time to respond to its inputs.

Q̅ = (S + Q)′; Q = (R + Q̅)′.
Q comes from the R gate; Q̅ comes from the S gate. The label Q̅ denotes the complementary output during valid operation; the outputs need not be complements during the forbidden condition.

Step 1 — Hold SR = 11: a NOR gate gives 0 whenever any input is 1. Therefore, both outputs are forced low: QQ̅ = 00. This is a settled, forced output condition while 11 is applied, but it is invalid for storing a complementary output pair.

Step 2 — Change both inputs to 0 together: immediately after release, both outputs are still 0 because of gate delay. Each gate now sees inputs 00 and attempts to raise its output to 1. The two gates compete through the feedback connections.

Why can’t 00 simply be retained? With S = R = 0, a settled output pair must satisfy Q̅ = Q′ and Q = (Q̅)′. Thus QQ̅ = 10 or 01 are valid stable states; 00 is not a stable state under SR = 00.

Two reasons SR = 11 is forbidden: it forces the outputs to be equal, and releasing both inputs together does not guarantee a particular stored bit. The earlier bit has already been lost when both outputs were forced to 0.

Before and immediately after release: compare the input labels. The outputs initially remain the same, but after release both gates start trying to change them.

Use the slides’ ideal symmetric digital delay model: dS = dR = d, both inputs fall simultaneously, and both gates respond identically.

This sequence is a model used in the slides. Equal nominal gate delays do not guarantee sustained oscillation in a physical latch. Real behavior also depends on analog voltage changes, noise, and small differences between the two paths.

3.8 Case 2: GR Is Faster (dS > dR)

In the slides’ unequal-delay model, GR, the gate producing Q, responds first after SR changes from 11 to 00.

  1. Initially, QQ̅ = 00. Both gates attempt to produce 1 after release.
  2. The faster GR raises Q to 1 first.
  3. That 1 feeds back into GS, keeping Q̅ = (0 + 1)′ = 0.
  4. Q̅ = 0 supports Q = (0 + 0)′ = 1, so the feedback holds the state.

QQ̅ : 00 → 10 (stable set state).
GR faster → Q rises first → the latch stores 1.

Watch the gate names: GR being faster does not mean the latch resets. Once R is released to 0, its NOR gate can raise Q to 1.

3.9 Case 3: GS Is Faster (dR > dS)

Now GS, the gate producing Q̅, responds first after simultaneous release.

  1. Initially, QQ̅ = 00, and both gates attempt to produce 1.
  2. The faster GS raises Q̅ to 1 first.
  3. That 1 feeds back into GR, keeping Q = (0 + 1)′ = 0.
  4. Q = 0 supports Q̅ = (0 + 0)′ = 1, so the feedback holds the state.

QQ̅ : 00 → 01 (stable reset state).
GS faster → Q̅ rises first → the latch stores 0.

3.10 Practical Behavior and Exam Summary

SR : 11 → 00 — summary of the slides’ delay model
Delay conditionFirst output to riseResult for QQ̅
dS = dR, perfect symmetryBoth together00 → 11 → 00 → … (ideal oscillation)
dS > dR; GR fasterQ10 — set
dR > dS; GS fasterQ̅01 — reset

In practice: gate and wiring delays differ, inputs may not fall at exactly the same instant, and electrical noise can affect the race. The latch normally resolves to 10 or 01, but the input sequence alone does not specify which state wins.

If the two paths compete very closely, the latch can temporarily enter metastability: its internal voltages remain near an unstable intermediate level, so a valid logic output is not guaranteed until it resolves. Metastability is different from the ideal alternating 00/11 sequence.

The unequal-delay rows describe the simplified model used in the slides, assuming the faster response suppresses the other gate’s rising response. Exact transients in a real circuit depend on its electrical characteristics and input timing.

GATE takeaway: for SR : 11 → 00, use the stated delay assumptions. Equal ideal delays give the slide’s oscillation sequence; a specified faster gate determines the state in that model. With no timing information, the final stored bit is indeterminate.

For a complementary reference on the unknown state after simultaneous release, see KFUPM’s Sequential Circuits lecture notes.

3.11 Why 11 → 10 and 11 → 01 Have Defined Results

If one input remains asserted, it forces one output low while the other output settles. This removes the simultaneous-release competition.

Defined recovery sequences:
SR : 11 → 10 → 00  ⇒  set, then retain Q = 1.
SR : 11 → 01 → 00  ⇒  reset, then retain Q = 0.
Allow each intermediate state to settle. In normal operation, avoid SR = 11 altogether.

04

SR Latch with Cross-Coupled NAND Gates

Two cross-coupled NAND gates store one bit, with user inputs to set, reset, or retain it. Unlike the NOR latch, the NAND latch has active-low control inputs.

4.1 NAND: Input 0 Dominates

A NAND gate outputs the complement of the AND of its inputs. If either input is 0, its output is 1, regardless of the other input.

(0 · X)′ = 1 for either X = 0 or X = 1.
With the control input at 1, (1 · X)′ = X′: the gate acts as an inverter.

4.2 Which Input Is Set? Which Is Reset?

Keep the slide’s output choice: the right output is Q, and the left output is labelled Q̅. Identify each control by its effect on Q:

  • B = 0 forces the right NAND output Q = 1 → B is the active-low set input, S̅.
  • A = 0 forces the left output Q̅ = 1; with B = 1, this makes Q = 0 → A is the active-low reset input, R̅.

A = R̅; B = S̅. Here the input driving the NAND gate that produces Q is the set input. Identify controls from their effect, rather than copying the NOR labels.

Gate equations: Q = (S̅ · Q̅)′; Q̅ = (R̅ · Q)′.

4.3 Active-Low Operation

Active low means a control performs its named action when it is 0. The slides write these inputs as S and R; here, bars explicitly indicate their active-low nature. Input pairs below are ordered S̅R̅, not AB.

NAND latch: values after settling

01 → set; 10 → reset; 11 → retain; 00 → forbidden.
For set: S̅ = 0 forces Q = 1, then R̅ = 1 gives Q̅ = 0. For reset, the reasoning is reversed.

4.4 Forbidden Input vs Unpredictable Release

At S̅R̅ = 00, both NAND outputs are forced to 1. These levels are stable while both inputs remain low, but this is not a valid stored bit because Q and Q̅ are equal.

The uncertainty occurs when both inputs rise together: 00 → 11. Neither control remains asserted to select a state; the final stored bit depends on timing differences and may involve metastability.

Compare forbidden-to-hold transitions
LatchForbidden inputsForced outputs QQ̅Simultaneous release to hold

Distinguish the two: forbidden inputs force known, equal output levels; simultaneous release to hold does not guarantee which valid bit will be stored.

Solved Questions: SR Latches

Check the gate type and whether the question asks about fixed inputs or an input transition.

Q1. NAND Latch with Both Inputs 0

GATE CSE 2004 · Question 18 · Also shown as ISRO 2007, Q31

In an SR latch made by cross-coupling two NAND gates, if both S and R inputs are set to 0, then it will result in:

  1. Q = 0, Q′ = 1
  2. Q = 1, Q′ = 0
  3. Q = 1, Q′ = 1
  4. Indeterminate states

Solution: each NAND gate has a 0 at its control input. Since (0 · X)′ = 1, both outputs are forced to 1, regardless of feedback.

Answer: C — Q = 1, Q′ = 1.

Why not D? With inputs held at 00, the output levels are known and stable, although this is a forbidden input combination. Uncertainty arises on simultaneous release 00 → 11.

Here Q′ is the question’s label for the second output. It is not the logical complement of Q during the forbidden condition.

Solution: 00 first forces both outputs to 1. When both inputs rise together to 11, neither input forces a particular stored bit. In the ideal equal-delay model, both gates can respond together:

Q8. Critical Path Delay of a NAND Latch

Critical path delay = 1 ns + 1 ns = 2 ns.

06

Introduction to Flip-Flops

6.1 Problem with Basic Latches

  • Basic latches can change state when their input signals change.
  • It is difficult to control when these inputs change and, therefore, when the latch may change its state.
  • We need a way to control when the storage device responds to its inputs.

Desired behavior: respond to inputs when we want it to; otherwise, retain the current state regardless of input changes.

This need for controlled state changes motivates the use of flip-flops.

6.2 Flip-Flops: Controlled State Changes

Like a latch, a flip-flop is a single-bit storage device. Unlike a basic latch, its state updates only at a specific instant controlled by a clock signal.

How the clock controls the response
WhenBehavior
At the clock-controlled instantResponds to the inputs.
At other timesRetains its current state, regardless of input changes.

6.3 Definition of a Flip-Flop

A flip-flop stores one bit of binary information: 0 (reset state) or 1 (set state).

A flip-flop is an edge-triggered, clocked storage element.

07

Clock Signal in Sequential Circuits

A clock is a signal that repeatedly oscillates between logic level 0 and logic level 1. It is a periodic square-wave signal with a constant frequency.

7.1 Clock Levels and Edges

Clock terminology
TermMeaning
HIGH level / Positive levelClock is at logic 1.
LOW level / Negative levelClock is at logic 0.
Rising edge / Positive edgeTransition from 0 to 1.
Falling edge / Negative edgeTransition from 1 to 0.

7.2 High Time and Low Time

  • TH (high time): duration for which the clock remains at logic 1.
  • TL (low time): duration for which the clock remains at logic 0.

Remember: a level describes the clock’s value; an edge describes a change in that value. TH and TL describe the durations of the two levels.

7.3 Clock Cycle and Clock Period

  • Clock cycle: one complete cycle consists of one HIGH phase and one LOW phase, with one rising edge and one falling edge.
  • Clock period (T): time taken for one complete clock cycle.
  • Measure T between two consecutive rising edges or two consecutive falling edges.

T = TH + TL.
Clock period = period = cycle time = time period.

7.4 Clock Frequency

Clock frequency (f) is the number of complete clock cycles per second. It tells us how fast the clock cycles repeat.

f = 1/T.
Period T: seconds per cycle. Frequency f: cycles per second.
1 Hz (hertz) = 1 cycle per second. Use T in seconds to obtain f in Hz.

Units: period is measured in seconds (s), microseconds (µs), nanoseconds (ns), etc.; frequency is measured in hertz (Hz).

7.5 Duty Cycle of a Clock Signal

The duty cycle is the percentage of the clock period for which the clock remains HIGH.

Duty cycle = (TH / T) × 100% = [TH / (TH + TL)] × 100%.

  • TH: high time = high pulse width (or pulse width).
  • TL: low time = low pulse width.

Worked Examples from the Slides

THTLPeriod TDuty cycle
5 ns5 ns5 + 5 = 10 ns(5/10) × 100% = 50%
4 ns6 ns4 + 6 = 10 ns(4/10) × 100% = 40%

Default assumption in these notes: use a 50% duty cycle unless stated otherwise. Then TH = TL = T/2.

SR Flip-Flop (Set–Reset Flip-Flop)

An SR flip-flop has S (Set) and R (Reset) inputs, a clock input, and outputs Q and Q̅. Q is the main stored output.

Same set, reset, and hold behavior as the active-high SR latch, but the flip-flop responds at its active clock edge.

00 → retain; 01 → reset; 10 → set; 11 → forbidden.

For SR = 00, the next state equals Q. Reset and set force the next state to 0 and 1 respectively, regardless of Q. The two rows with SR = 11 are forbidden.

8.4 Deriving the Characteristic Equation

The characteristic equation is a Boolean expression for the next output QN. Plot the expanded table on a three-variable K-map, with rows Q and columns SR in Gray-code order: 00, 01, 11, 10.

  1. Blue group of four: combine columns 11 and 10 across both rows. R and Q vary; only S = 1 remains. This gives the term S.
  2. Pink wraparound pair: combine the bottom-row cells in columns 00 and 10. S varies, while R = 0 and Q = 1 remain. This gives R̅Q.
  3. OR the two terms to obtain the next-state equation.

QN = S + R̅Q, with SR = 0 (S and R must not both be 1).
Equivalently, Q(t + 1) = S + R̅Q(t).

Quick check: SR = 00 gives QN = Q; SR = 01 gives QN = 0; SR = 10 gives QN = 1.

The restriction still applies: using the forbidden rows as don’t-cares simplifies the expression; it does not make SR = 11 a valid input combination.

8.5 Excitation Table

An excitation table gives the inputs needed to produce a required transition from the present state Q to the next state QN.

SR flip-flop: required inputs for each state transition

X means don’t-care: either 0 or 1 produces the required transition. For 0 → 0, R can be either value while S = 0. For 1 → 1, S can be either value while R = 0.

Characteristic table: inputs + present state → next state.
Excitation table: present state + desired next state → required inputs.

Remember: output = state = stored bit. The don’t-cares above never require the forbidden combination S = R = 1.

8.6 State Diagram

A state diagram shows how a flip-flop moves from one state to another. The nodes represent states, and the directed arrows are labelled with the inputs that cause each transition.

  • From Q = 0: SR = 10 moves to Q = 1; SR = 00 or 01 keeps Q = 0.
  • From Q = 1: SR = 01 moves to Q = 0; SR = 00 or 10 keeps Q = 1.

Read an arrow as: present state + indicated SR input → next state at the active clock edge.
SR = 11 is forbidden, so it has no valid transition in this diagram.

JK Flip-Flop

A JK flip-flop behaves like an SR flip-flop with J corresponding to S and K corresponding to R, except for the 11 input combination.

JK = 11 causes toggle: the next state is the complement of the present state, QN = Q̅. Unlike SR = 11, it is not forbidden.

9.1 Logic Symbol and Characteristic Table

1010Set
11Q̅QToggle

Here Q is the present state and QN is the next state at the active clock edge. Toggle means 0 → 1 or 1 → 0.

00 → retain; 01 → reset; 10 → set; 11 → toggle.

9.2 Expanded Truth Table

The next output depends on the present inputs and stored state: QN = f(J, K, Q).

Key difference from SR: the final two rows are defined. For JK = 11, the stored bit is complemented.

9.3 Deriving the Characteristic Equation

Plot QN on a three-variable K-map, with rows Q and columns JK in Gray-code order: 00, 01, 11, 10.

  1. Blue top-row pair: columns 11 and 10 have J = 1 and Q = 0; K varies. This gives JQ̅.
  2. Pink bottom-row wraparound pair: columns 00 and 10 have K = 0 and Q = 1; J varies. This gives K̅Q.
  3. OR the terms to obtain the next-state equation.

QN = JQ̅ + K̅Q.
Equivalently, Q(t + 1) = JQ̅(t) + K̅Q(t).

Quick check: JK = 00 gives QN = Q; 01 gives 0; 10 gives 1; 11 gives Q̅.

9.4 Excitation Table

Given the present state Q and the desired next state QN, the excitation table tells us which J and K inputs produce that transition.

X means don’t-care: either 0 or 1 works for that input in the specified transition.

Shortcut: when Q = 0, J determines the next state and K is irrelevant. When Q = 1, K determines whether to reset or retain, and J is irrelevant.

The two nodes represent the stored states Q = 0 and Q = 1. Each arrow is labelled with the JK input combinations that cause that transition at the active clock edge.

  • From Q = 0: JK = 00 or 01 keeps Q = 0; JK = 10 or 11 changes Q to 1.
  • From Q = 1: JK = 00 or 10 keeps Q = 1; JK = 01 or 11 changes Q to 0.

JK = 11 toggles in either state: 0 → 1 and 1 → 0.

Edge-Triggered Flip-Flops

An edge-triggered flip-flop responds at a specific clock transition. The triggering edge may be positive (rising) or negative (falling).

10.1 Positive-Edge-Triggered Flip-Flop

The flip-flop can change its stored state only at the positive / rising edge of the clock: 0 → 1.

Rising edge → respond to inputs.
At other times, retain the current state regardless of input changes.

10.2 Negative-Edge-Triggered Flip-Flop

The flip-flop can change its stored state only at the negative / falling edge of the clock: 1 → 0.

Falling edge → respond to inputs.
At other times, retain the current state regardless of input changes.

10.3 Reading the Clock-Input Symbol

D Flip-Flop (Data Flip-Flop)

An SR flip-flop uses two inputs, S and R, to decide what to store. A D flip-flop uses just one data input, D: at the active clock edge, it stores the value present at D.

11.1 From Two Inputs to One

Recall the active-high SR flip-flop: S sets the output, R resets it, and the clock controls when it responds.

SR behavior used in the construction
SRQNOperation
00QHold
010Reset
101Set

To store 0, choose SR = 01. To store 1, choose SR = 10. In both cases the controls are complementary, so we can generate them from one input and an inverter.

11.2 Constructing D from an SR Flip-Flop

Connect D directly to S and inverted D to R. The clock still controls the SR flip-flop.

S = D; R = D̅.

Test both possible D values at the active clock edge

001Reset: store 00

QN = D. Whatever binary value is applied to D is the value captured at the active clock edge.

T Flip-Flop (Toggle Flip-Flop)

A T flip-flop has one control input, T, which determines whether to retain the stored bit or toggle it at the active clock edge. T stands for Toggle.

T = 0 → hold: 0 stays 0; 1 stays 1.
T = 1 → toggle: 0 becomes 1; 1 becomes 0.

12.1 Logic Symbol and Truth Table

Characteristic table, expanded for both present states
TQQNOperation
000Hold
011Hold
101Toggle
110Toggle

Q is the present state; QN is the next state. Unlike D, which specifies the value to store, T specifies whether to change the value already stored.

12.2 Constructing T from a JK Flip-Flop

A JK flip-flop holds for JK = 00 and toggles for JK = 11. Connect both J and K to the same input T to select just these two operations.

TJKJK operationQN
000HoldQ
111ToggleQ̅

T flip-flop = JK flip-flop with J = K = T.

12.3 Characteristic Equation

The next state is the XOR of T and the present state Q. XOR leaves Q unchanged when T = 0 and complements it when T = 1.

QN = T ⊕ Q = TQ̅ + T̅Q.

We can also obtain this directly from the JK equation: substitute J = K = T into QN = JQ̅ + K̅Q to get QN = TQ̅ + T̅Q.

This makes T flip-flops useful in counters and frequency dividers.
