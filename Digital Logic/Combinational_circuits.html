Combinational Circuits

01

Introduction

A combinational circuit is a digital circuit whose outputs depend only on the present combination of inputs. It is built using logic gates and has no memory of previous inputs. Each output is a Boolean function of the inputs; for example, a circuit with inputs A and B may produce Y = A · B.

For a given input combination, the circuit produces a fixed output combination after the gates' propagation delay; the output does not change instantaneously. Its behavior can be described using a truth table or Boolean expressions, and Boolean algebra or K-maps can simplify the logic before implementation.

2.4 Four-Variable Function Using a 4 × 1 MUX

A MUX can implement a Boolean function as well as select data. Here, C and D are the select inputs (S1 = C, S0 = D), while the data inputs are functions of A and B.

Write one term for each select combination: multiply each data input by the select condition that chooses it, then OR the terms.

Z = C′D′(A′ + B′) + C′D(A′) + CD′(AB′ + A′B) + CD(0)

Simplification: combine A′C′D′ and A′C′D to get A′C′. The remaining terms reduce as follows:

Z = A′C′ + B′C′D′ + AB′CD′ + A′BCD′

Split B′C′D′ using A + A′ = 1. Its A′ part is absorbed by A′C′, and its A part combines with AB′CD′ to give AB′D′. Also, A′C′ + A′BCD′ = A′(C′ + BD′).

Minimized output

Z = A′C′ + A′BD′ + AB′D′

3.3 Demux Applications: Practice Question

A demultiplexer is used to:

  • (A) Route the data from a single input to one of many outputs.
  • (B) Perform serial-to-parallel conversion.
  • (C) Both (A) and (B).
  • (D) Select data from several inputs and route it to a single output.
Show answer and explanation

Correct option: (C), both (A) and (B). A Demux routes one input to a selected output and can be used with control and storage to perform serial-to-parallel conversion. Option (D) describes a multiplexer.

Serial-to-Parallel Conversion Using a 1 × 8 Demux

A serial stream supplies one bit at a time to D. A synchronized 3-bit counter steps through the select codes 000, 001, 010, 011, 100, 101, 110, and 111, routing successive bits to Y0 through Y7.

Storage is necessary: a Demux has no memory. When the select code changes, the previous output returns to 0. Each storage cell must capture only during its assigned time slot and hold its value during the other slots.

Sequence: select 000 and store b0; select 001 and store b1; continue through 111 and store b7. Advance the counter once per received bit, with capture timed while that bit and its select code are stable.

Functionally Complete

A set of logic gates is functionally complete if all switching functions can be realized using only gates from this set.

4.1 Result 1: {AND, OR, NOT} Is Functionally Complete

Claim: every Boolean function can be implemented using only AND, OR, and NOT gates.

Example: consider the following three-input function. The rows with output 1 are minterms m1, m4, m5, and m6.

Example truth table (x1 is the MSB)
Indexx1x2x3f

71110

f = Σm(1, 4, 5, 6)

Construct the minterms: a 0 in the input row gives a complemented variable; a 1 gives an uncomplemented variable. AND the three literals in each row.

m1 = x1′x2′x3
m4 = x1x2′x3′
m5 = x1x2′x3
m6 = x1x2x3′

Canonical SOP implementation

f = x1′x2′x3 + x1x2′x3′ + x1x2′x3 + x1x2x3′

NOT produces complemented variables, AND forms each minterm, and OR combines the minterms.

General proof: take any Boolean function of n input variables.

  1. Write its truth table and identify every row where the output is 1.
  2. For each such row, form a minterm using AND and NOT. That minterm is 1 exactly on that row.
  3. OR these minterms together. The result is 1 on exactly the required rows, so it equals the original function.

Constant functions are covered too: if no row has output 1, implement f = 0 as x · x′. Implement f = 1 as x + x′. Gates with more inputs can be built by cascading two-input gates.

Therefore, {AND, OR, NOT} is functionally complete. The construction works for any number of input variables and any truth-table output pattern.

GATE takeaway: every Boolean function has a canonical SOP representation, and this representation requires only AND, OR, and NOT.

4.2 Result 2: {AND, NOT} Is Functionally Complete

We already know that {AND, OR, NOT} is functionally complete. The set {AND, NOT} can implement the missing OR operation using De Morgan’s law:

Create OR using AND and NOT

A + B = (A′ · B′)′

  1. Invert A and B using NOT gates to obtain A′ and B′.
  2. AND the complemented inputs: A′ · B′.
  3. Invert the result to obtain A + B.

Thus, every OR gate in an AND–OR–NOT implementation can be replaced by this construction. All three operations are available using only AND and NOT, so {AND, NOT} is functionally complete.

4.3 Result 3: {OR, NOT} Is Functionally Complete

The set {OR, NOT} can implement the missing AND operation using the other De Morgan identity:

Create AND using OR and NOT

A · B = (A′ + B′)′

  1. Invert A and B using NOT gates to obtain A′ and B′.
  2. OR the complemented inputs: A′ + B′.
  3. Invert the result to obtain A · B.

Thus, every AND gate in an AND–OR–NOT implementation can be replaced by this construction. All three operations are available using only OR and NOT, so {OR, NOT} is functionally complete.

GATE takeaway: AND with NOT can create OR; OR with NOT can create AND. Both sets can therefore implement every Boolean function.

4.4 All Basic Gates Using Only NAND

A NAND gate produces (AB)′. By connecting NAND gates together, we can realize NOT, AND, OR, NOR, XOR, and XNOR as well as NAND itself.

Reading the diagrams: each symbol is a two-input NAND gate. Matching signal labels within an implementation represent connected wires; N1, N2, etc. are intermediate signals. A dot marks a branch where one signal feeds both inputs. Gate counts refer to the constructions shown.

1. NOT using NAND — 1 gate

Tie both inputs of one NAND gate to A. Since AA = A, the output is A′.

Y = A NAND A = A′

2. AND using NAND — 2 gates

First NAND A and B, then invert that result with a NAND gate whose inputs are tied together.

N1 = (AB)′;   Y = (N1N1)′ = AB

3. OR using NAND — 3 gates

Generate N1 = A′ and N2 = B′ using tied-input NAND gates, then NAND these signals. De Morgan’s law gives OR.

Y = (A′B′)′ = A + B

4. NAND using NAND — 1 gate

The required operation is already a NAND, so one gate is sufficient.

Y = (AB)′

5. NOR using NAND — 4 gates

Build OR using three NAND gates, then invert its output using a fourth tied-input NAND.

N3 = A + B;   Y = (N3N3)′ = (A + B)′

Share N1 = (AB)′ between the next two gates. Their outputs are N2 = A′ + B and N3 = A + B′. The final NAND produces XOR.

Y = N2 NAND N3 = A′B + AB′ = A ⊕ B

4.6 Post’s Theorem: Properties of Boolean Functions

Post’s theorem provides a criterion for deciding whether a set of Boolean functions is functionally complete. Let X = {f1, f2, …, fk} be the available set. We begin with the first property to check: whether its functions preserve 0.

Step 1: Simplify and Remove Dummy Variables

Simplify each function and identify the variables its output actually depends on. A dummy variable is an input whose value never changes the output when the other inputs are fixed.

f(a, b) = a + ab = a

By absorption, the output is independent of b. Remove the dummy variable b and write f(a) = a.

This is a useful preparation step; full minimization is not required to apply the theorem or evaluate f(0, …, 0).

Property 1: 0-Preserving Functions

A Boolean function is 0-preserving if its output is 0 when all its inputs are 0.

f(0, 0, …, 0) = 0

For three inputs, check f(0, 0, 0). For a unary function, check f(0). Only the all-zero input row matters for this property.

Result 1: A Set of Only 0-Preserving Functions Is Not Complete

If every function fi in X is 0-preserving, then X is not functionally complete.

Why? Set every external input to 0. Each gate in the first stage receives only zeros, so it outputs 0. Every later stage also receives only zeros and outputs 0. Thus, any circuit built from these functions remains 0-preserving.

Such a circuit cannot realize a function like NOT, because NOT(0) = 1. Therefore, it cannot realize all Boolean functions. This argument uses only the functions in X; an external constant-1 source is not supplied for free.

Example: X = {AND, OR, XOR} is not functionally complete because every member outputs 0 on all-zero inputs.

GATE takeaway: a functionally complete set must contain at least one function that is not 0-preserving. This condition alone does not prove completeness; it only passes the first check.

A Boolean function is 1-preserving if its output is 1 when all its inputs are 1.

f(1, 1, …, 1) = 1

For three inputs, check f(1, 1, 1). For a unary function, check f(1). Only the all-one input row matters for this property.

Remember: preserving 0 and preserving 1 are separate properties. AND and OR preserve both; binary XOR preserves 0 but not 1; binary XNOR preserves 1 but not 0.

Property 3: Self-Dual Functions

A function is self-dual if it equals its dual: f = fd. The dual can be obtained by swapping AND with OR and 0 with 1 in a Boolean expression. Equivalently:

fd(x1, …, xn) = [f(x1′, …, xn′)]′

Self-dual test: complement every input; the output must also complement.

In a truth table, compare complementary input pairs. For three inputs these are 000/111, 001/110, 010/101, and 011/100. Every pair must have opposite output values; one equal-output pair disproves self-duality.

Examples: f(a) = a and f(a) = a′ are self-dual. AND is not: inputs 01 and 10 are complements, but AND outputs 0 for both. Having equal numbers of 0s and 1s in the output column is necessary for self-duality, but is not sufficient.

Result 3: if every function fi in X is self-dual, then X is not functionally complete.

Reason: composing self-dual functions preserves self-duality. Complementing all external inputs complements each intermediate signal and the final output. Hence such circuits cannot realize a non-self-dual function such as AND.

Property 4: Linear Functions

In these Post’s theorem notes, linear includes affine Boolean functions: XORs of a subset of the variables, optionally XORed with the constant 1.

f = c0 ⊕ c1x1 ⊕ … ⊕ cnxn,   ci ∈ {0, 1}

All additions here are XOR. Products such as x1x2 are absent from this form. In stricter algebra terminology, “linear” requires c0 = 0; “affine” allows either constant.

First remove dummy variables. Every remaining variable has coefficient 1. Thus, for a nonconstant function, the truth table must follow one of two parity patterns:

Why remove dummy variables? For f(a, b) = a, b has no effect. Counting 1s in both a and b would give a misleading parity test; after removing b, f(a) = a follows odd parity.

Property 5: Monotonic Functions

A Boolean function is monotonic (monotone increasing) if changing any single input variable from 0 to 1, while keeping all other inputs fixed, never decreases the output. This must hold for every such change in the truth table.

Allowed: 0 → 0, 0 → 1, and 1 → 1.

Not allowed: 1 → 0.

Equivalently, if each input bit of x is less than or equal to the corresponding bit of y, then f(x) ≤ f(y). Testing every single-bit increase is sufficient, because multiple increases can be performed one at a time.

Result 5: A Set of Only Monotonic Functions Is Not Complete

If every function fi in X is monotonic, then X is not functionally complete.

Reason: compositions of monotonic functions remain monotonic. Increasing external inputs cannot decrease any first-stage output, any later-stage output, or the final output. Such circuits cannot implement NOT, whose output decreases from 1 to 0 when its input increases from 0 to 1.

Example: {AND, OR} is not functionally complete. Both functions are monotonic, and combining them cannot produce a nonmonotonic function.

GATE takeaway: a functionally complete set must contain at least one nonmonotonic function. Passing this check alone does not prove completeness.

Summary: Post’s Completeness Criterion

Let X = {f1, f2, …, fk} be a set of Boolean functions. The set is functionally complete if and only if it is not entirely contained in any one of the five classes T0, T1, S, L, or M.

All five requirements must hold for functional completeness
ClassPropertyRequired in X
T00-preservingAt least one function with f(0, …, 0) = 1
T11-preservingAt least one function with f(1, …, 1) = 0
SSelf-dualAt least one function that is not self-dual
LLinear (affine)At least one function that is not linear
MMonotonicAt least one function that is not monotonic

Quick rejection rule: X is not functionally complete if every function in X is 0-preserving, or every function is 1-preserving, or every function is self-dual, or every function is linear, or every function is monotonic.

Otherwise, X is functionally complete. It must escape all five classes.

Watch the quantifiers: a different function may satisfy each requirement. One function does not have to violate all five properties. To prove incompleteness, however, one property must be shared by every function in the set.

This criterion uses only the functions available in X and their compositions. If constant sources are supplied, include them in the available set when checking the properties.

Create NOT: tie the second implication input to 0.

We have obtained {OR, NOT}, which is functionally complete. Therefore, {→, 0, 1} is functionally complete. In fact, constant 0 alone suffices with implication; constant 1 is not needed for these constructions.

4.9 GATE ECE 2015, Set 3: Universal Gate (Question 37)

A universal logic gate can implement any Boolean function by connecting a sufficient number of them appropriately. Three gates are shown. Which one of the following statements is true?

  • (A) Gate 1 is a universal gate.
  • (B) Gate 2 is a universal gate.
  • (C) Gate 3 is a universal gate.
  • (D) None of the gates shown is a universal gate.
Show solution

Correct option: (C), Gate 3. Use the circuit convention that constant inputs 0 and 1 are available.

Gates 1 and 2: OR and AND are monotonic. Constant functions are also monotonic, so including 0 and 1 cannot break this restriction. Their respective gate sets cannot produce NOT and are not universal.

Gate 3: let G(X, Y) = X′ + Y. Connect its second input to 0 to obtain NOT, then use the inverted input to obtain OR.

G(X, 0) = X′

G(G(X, 0), Y) = (X′)′ + Y = X + Y

Gate 3 implements {OR, NOT}, a functionally complete set. Therefore it is universal with constant inputs available.

This is the implication-gate result from Sections 4.7 and 4.8. If constants were forbidden, implication alone would preserve 1 and would not be functionally complete.

Easy Way to Remember

  • NOT: satisfies only self-duality and affinity.
  • AND, OR: satisfy 0-preservation, 1-preservation, and monotonicity.
  • NAND, NOR: satisfy none of the five properties.
  • Binary XOR, XNOR: both are affine. XOR preserves 0; XNOR preserves 1.
  • Biimplication: A ↔ B = AB + A′B′ = 1 ⊕ A ⊕ B, so it is the same as binary XNOR. It satisfies only 1-preservation and affinity.
  • Implication (either direction): satisfies only 1-preservation.
  • Constants 0 and 1: both are monotonic and affine. Constant 0 preserves 0; constant 1 preserves 1.
  • Identity: satisfies all five properties.

Decoder

Decoding means converting an input binary code into its corresponding output. A decoder is a combinational circuit that activates the one output whose number matches the binary input code.

For an active-high decoder, exactly one output is 1 for each valid input combination; all remaining outputs are 0. This is called one-hot output.

An n-bit binary input has 2n possible combinations. Therefore, an n-to-2n decoder has n input lines and 2n output lines.

Encoder

An encoder converts an active input line into its binary code. It performs the inverse operation of a decoder: a decoder takes an n-bit code and activates one of 2n outputs, while an encoder takes one of 2n active input lines and produces an n-bit output.

A basic encoder assumes exactly one input is 1 at a time. If multiple inputs can be 1, their code is ambiguous; a priority encoder is used when one input must take precedence.
