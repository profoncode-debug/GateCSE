Introduction to TOC

1.1 Alphabet

An alphabet is a nonempty, finite set of symbols. It is usually denoted by Σ (capital Greek letter sigma).

  • Nonempty: an alphabet must contain at least one symbol.
  • Finite: the number of symbols must be finite.
  • Symbol: an element of an alphabet; each symbol is an atomic entity, treated as a single indivisible unit of length 1.

Example: English Alphabet

Taking the lowercase English letters as symbols:

Σ = {a, b, c, …, y, z}
Here, a, b, …, z are individual symbols. Each has length 1: |a| = |b| = … = |z| = 1.

Types of Alphabets

An alphabet can be classified by the number of symbols it contains.

TypeNumber of SymbolsExample
Unary alphabet1Σ = {a}
Binary alphabet2Σ = {a, b} or Σ = {0, 1}
Ternary alphabet3Σ = {0, 1, 2}

Remember: “binary” means an alphabet has two symbols; those symbols need not be 0 and 1. The length of each symbol is 1, while the size of the alphabet, written |Σ|, counts how many symbols it contains.

1.2 Strings

A string over an alphabet Σ is a finite sequence of symbols, where every symbol belongs to Σ.

  • Order matters: ab ≠ ba, even though both use the same symbols.
  • Repetition matters: aa ≠ aaa. A symbol can appear more than once in a string.
  • Alphabet restriction: a string may use only symbols from the given alphabet; it need not use every symbol.

Examples over Different Alphabets

AlphabetValid StringsInvalid String and Reason
Σ1 = {a, b}abaa, aa, aaa, ab, baabc: c ∉ Σ1
Σ2 = {a}a, aa, aaa, aaaaaab: b ∉ Σ2

Length of a String

The length of a string w, written |w|, is the number of symbol occurrences in it. Count repeated symbols each time they occur.

For w = 000 over Σ = {0, 1}, |w| = 3. Although only one distinct symbol appears, the string contains three symbol occurrences.

More Examples

String wAlphabetLength |w|
1010Σ1 = {0, 1}4
1234Σ2 = {1, 2, …, 9}4
theoryΣ3 = {a, b, …, z}6

Alphabet vs string: an alphabet is a set of available symbols; a string is an ordered sequence formed from them. For Σ = {a, b}, |Σ| = 2, while the string abaa has length 4.

1.3 Empty String

The empty string (or null string), denoted by ε or λ, is the string containing no symbols.

  • Length zero: |ε| = |λ| = 0.
  • Not an alphabet symbol: ε ∉ Σ. Every alphabet symbol has length 1; the empty string has length 0.
  • A string over every alphabet: containing no symbols does not violate any alphabet restriction.

Empty String vs Empty Set

The empty string is a sequence; the empty set is a set with no elements. A set containing the empty string has one element.

NotationMeaningLength or Cardinality
εEmpty string|ε| = 0 (string length)
∅ = {}Empty set|∅| = 0 (number of elements)
{ε}Set containing the empty string|{ε}| = 1 (number of elements)

Do not confuse: ε, {ε}, and ∅ are different objects. In particular, ε ∈ {ε}, but ε ∉ ∅. The zero length of ε does not make {ε} an empty set.

1.4 Strings vs Sets

Recall: an alphabet is specifically a nonempty finite set, even though sets in general may be infinite.

Q1. How Many Strings Are There over Σ = {a}?

Question: Let Σ = {a}. How many strings can be formed over Σ?

Solution: The strings are ε, a, aa, aaa, aaaa, …. For every nonnegative integer n, there is exactly one string of length n: an, meaning n copies of a, with a0 = ε.

Stringεaaaaaaaaaa…
Length01234…

Answer: infinitely many strings. Each individual string has finite length, but there is no maximum length. The ellipsis lists more finite strings; it does not represent a single infinitely long string.

1.5 Counting Strings

If an alphabet has k symbols, each position of a string has k independent choices. For a nonnegative integer n:

Strings of length n = kn.
There is exactly one length-0 string: ε. If r distinct positions are fixed to specified alphabet symbols, the remaining n − r positions give kn − r strings.

Q2. Strings of Length 5 or n over {a, b, c}

Solution: Each position has 3 choices, with repetition allowed.

Length 5: 35 = 243.
Length n: 3n.

Q3. Length 7, with First, Middle, and Last Symbols Fixed to b

Over Σ = {a, b, c}, the required pattern is b _ _ b _ _ b. Positions 1, 4, and 7 are fixed; four positions remain free.

Answer: 1 × 3 × 3 × 1 × 3 × 3 × 1 = 34 = 81.

Q4. Strings of Length at Most 5 over {a, b, c}

Include every length from 0 through 5, so the empty string is counted once.

Answer: 1 + 3 + 32 + 33 + 34 + 35 = 364.

General rule: strings of length at most n = ∑i = 0n ki = (kn + 1 − 1)/(k − 1) for k > 1. For a unary alphabet (k = 1), the count is n + 1.

1.6 Reversal

The reversal of a string w is the string obtained by writing its symbols in reverse order. It is denoted by wR.

If w = a1a2…an, then wR = anan − 1…a1.
Example: w = abaa ⇒ wR = aaba.

Reversing ε gives ε: εR = ε.

1.7 Palindrome Strings

A palindrome is a string that reads the same forward and backward.

w is a palindrome ⇔ w = wR.

Examples: otto, madamimadam, 0110, 11011, and ε. Every single-symbol string is also a palindrome.

Nonexample: ab is not a palindrome because (ab)R = ba ≠ ab.

1.8 Concatenation

The concatenation of strings w and x, written wx, places all symbols of x immediately after all symbols of w.

For w = abaa and x = ab:
wx = abaaab, while xw = ababaa.

Properties

Examples with several strings: for w1 = ab, w2 = b, and w3 = aa:

  • w1w2w1 = abbab.
  • w1w1w2w3 = ababbaa.
  • w1w2 = abb, while w2w1 = bab.

Length example: x = abaa, y = aa ⇒ xy = abaaaa, so |xy| = 4 + 2 = 6.

1.9 Powers of a String

For a nonnegative integer n, wn means the concatenation of n copies of w.

w0 = ε by definition; w1 = w.
wn + 1 = wnw = wwn.

Zero copies always give ε: ε0 = (ab)0 = a0 = b0 = ε.

1.10 Prefix, Suffix, and Substring

Let w and x be strings over the same alphabet. In the formal definitions below, ⇔ means if and only if.

TermMeaningFormal Condition
Prefix xInitial part of wx is a prefix of w ⇔ w = xy for some string y
Suffix xFinal part of wx is a suffix of w ⇔ w = yx for some string y
Substring xConsecutive part of wx is a substring of w ⇔ w = yxz for some strings y and z

Reading the decompositions: in w = xy, x is at the beginning; in w = yx, x is at the end; in w = yxz, x is a consecutive block between y and z. The surrounding strings y and z are over the same alphabet and may be ε.

ε and w itself are prefixes, suffixes, and substrings of w. A proper prefix or proper suffix is any prefix or suffix except w itself; for a nonempty w, ε is proper.

Example: w = abaab

Prefixes: ε, a, ab, aba, abaa, abaab.
Proper prefixes: ε, a, ab, aba, abaa.

Suffixes: ε, b, ab, aab, baab, abaab.
Proper suffixes: ε, b, ab, aab, baab.

Distinct substrings, grouped by length:

LengthDistinct Substrings of abaab
0ε

2ab, ba, aa
3aba, baa, aab
4abaa, baab
5abaab

Substring means consecutive: symbols cannot be skipped. In abaab, bb is not a substring, even though b appears twice. The table has 12 distinct substrings, including ε.

1.11 Counting Prefixes, Suffixes, and Substrings

Let |w| = n. There is exactly one prefix and one suffix of each length 0, 1, …, n.

Example: abc, aaa, and aba each have 4 prefixes and 4 suffixes because each has length 3. Repeated symbols do not change these counts.

Distinct Substrings Depend on the String

Different positions can produce the same substring. When counting distinct substrings, count each resulting string only once and include ε once.

StringDistinct SubstringsCount
aaaε, a, aa, aaa4
abcε, a, b, c, ab, bc, abc7
abaε, a, b, ab, ba, aba6

Minimum: Repeating One Symbol

For w = an, the distinct substrings are ε, a, a2, …, an: n + 1 in total.

Maximum: All Symbols Distinct

For w = a1a2…an with all symbols distinct, the n − ℓ + 1 occurrences of length ℓ are all distinct. Summing over nonzero lengths gives:

n + (n − 1) + … + 1 = n(n + 1)/2 nonempty substrings.
Including ε: n(n + 1)/2 + 1 distinct substrings.

For any string of length n: the number of distinct substrings, including ε, lies between n + 1 and n(n + 1)/2 + 1. All symbols being distinct is sufficient to attain the upper bound.

Counting reminder: there are always n(n + 1)/2 nonempty substring occurrences (choices of start and end positions). Repetitions can reduce the number of distinct substrings, so this formula is not always their exact count.

1.12 Subsequences

A subsequence of a string is obtained by deleting zero or more symbols without changing the relative order of the remaining symbols. The retained symbols need not be consecutive.

  • Example: acd is a subsequence of abcde: delete b and e.
  • Nonexample: aec is not a subsequence of abcde, because e occurs after c in the original string.
  • Boundary cases: deleting no symbols gives the original string; deleting all symbols gives ε. Both are subsequences.

Substring vs subsequence: a substring must be consecutive; a subsequence may skip symbols. For abc, ac is a subsequence but not a substring. Every substring is a subsequence.

Example: All Subsequences of ABCD

Both strings have length 3, but repeated symbols can make different selections of positions produce the same resulting string. For aaa, retaining any one of its three positions gives a.

Q5. How Many Subsequences When All Symbols Are Distinct?

Question: A string w has length n and all its symbols are distinct. How many distinct subsequences does it have?

Solution: Each of the n positions has two independent choices: keep or delete. Because all symbols are distinct, every choice of retained positions gives a different string.

Answer: 2n distinct subsequences, including ε.
For w = abcde: 25 = 32.
If only nonempty subsequences are counted: 2n − 1.

Counting reminder: any length-n string has 2n selections of positions, but these need not give 2n distinct strings when symbols repeat. For w = an, there are only n + 1 distinct subsequences: ε, a, a2, …, an.

1.13 Set of All Strings: Σ*

The set of all finite-length strings over an alphabet Σ is denoted by Σ* (read “sigma star”). It includes every string over Σ, including ε.

Example: Σ = {a, b}

Σ* = {ε, a, b, aa, ab, ba, bb, aaa, aab, aba, abb, baa, bab, bba, bbb, …}
The strings are listed by increasing length: first length 0, then length 1, then length 2, and so on.

Example: Unary Alphabet Σ = {a}

Σ* = {ε, a, aa, aaa, aaaa, …} = {an | n ≥ 0}.

  • Σ* is infinite: for a nonempty alphabet, strings can have arbitrarily large finite lengths.
  • Every member has finite length: Σ* is an infinite set of finite-length strings.
  • ε ∈ Σ*: the empty string is always included, though it is not an alphabet symbol.

1.14 Languages

A language over an alphabet Σ is any set of strings over Σ. Formally:

L ⊆ Σ*
A language selects some, all, or none of the strings in Σ*. It may be finite or infinite.

Examples over Σ = {a, b}

LanguageMeaning / MembersSize
L1 = {a, ab}Contains exactly the strings a and ab2 (finite)
L2 = Σ*Contains every string over {a, b}Infinite
L3 = {ap | p is prime}{a2, a3, a5, a7, a11, …}Infinite

In set-builder notation, the vertical bar | means “such that”. Thus {ap | p is prime} contains a string of p copies of a for each prime number p.

Empty Language and Singleton Languages

LanguageWhat It ContainsCardinality
∅ = {}No strings: the empty language0
{ε}Exactly one string: the empty string1
{a}Exactly one string: a1

ε is a string; {ε} is a language.
∅ ≠ {ε}: the empty language has no members, while {ε} has one member of length zero. The notation |L| counts strings in a language, while |w| counts symbols in a string.

A Finite Language Defined by a Pattern

Let L = {anbn | n is an integer and 0 ≤ n ≤ 100}. Each member has n copies of a followed by n copies of b.

L = {ε, ab, aabb, aaabbb, …, a100b100}
For n = 0: a0b0 = εε = ε. There is one distinct string for each of the 101 values of n, so |L| = 101.

1.15 Set Operations on Languages

Languages are sets of strings, so ordinary set operations apply. Let L1 and L2 be languages over the same alphabet.

OperationFormal DefinitionMembership Rule
UnionL1 ∪ L2 = {w | w ∈ L1 or w ∈ L2}In either language, including in both
IntersectionL1 ∩ L2 = {w | w ∈ L1 and w ∈ L2}In both languages
DifferenceL1 − L2 = L1 \ L2 = {w | w ∈ L1 and w ∉ L2}In L1, but not in L2
Symmetric differenceL1 Δ L2 = (L1 − L2) ∪ (L2 − L1)In exactly one of the two languages

Symmetric difference is also sometimes written L1 ⊕ L2.

Small Example

Take L1 = {ε, a, ab} and L2 = {a, b}.

  • Union: L1 ∪ L2 = {ε, a, ab, b}.
  • Intersection: L1 ∩ L2 = {a}.
  • Difference: L1 − L2 = {ε, ab}, while L2 − L1 = {b}.
  • Symmetric difference: L1 Δ L2 = {ε, ab, b}.

Remember: union includes common strings once; intersection keeps only common strings; symmetric difference removes common strings. Difference depends on the order of the languages.

1.16 Reversal of a Language

The reversal of a language L, denoted by LR, is the set obtained by reversing every string in L.

LR = {wR | w ∈ L}
Reverse each member individually; the order in which a set's members are listed does not matter.

Examples

Language LReversal LRComparison
{ab, aa, bab, ba}{ba, aa, bab, ab}L = LR: the same set of strings
{ab, abb, bb}{ba, bba, bb}L ≠ LR

|L| = |LR|. Reversal preserves cardinality: reversing twice gives the original string, so different strings have different reversals. This holds for finite and infinite languages.

Q6. If L = LR, Is Every String in L a Palindrome?

Answer: No. Take L = {ab, ba}. Then LR = {ba, ab} = L, but neither ab nor ba is a palindrome.

Reason: L = LR means that the reversal of every member is also in L. A string and its reversal may be different members of the same set.

Distinguish: w = wR says an individual string is a palindrome; L = LR says a language is closed under reversal.
If every string in L is a palindrome, then L = LR. The converse is false.

1.17 Language Concatenation

The concatenation of languages L1 and L2, written L1L2 or L1 · L2, is formed by concatenating each string from L1 with each string from L2, in that order.

L1L2 = {wx | w ∈ L1, x ∈ L2}
The result is a set of strings, so duplicate results are included only once.

1.18 Powers of a Language

For a nonnegative integer n, Ln is L concatenated with itself n times. Each factor independently contributes a string from L.

L0 = {ε}, L1 = L, and Ln + 1 = LnL.
For example, L4 = LLLL = {wxyz | w, x, y, z ∈ L}.

Q7. Find L2 for L = {anbn | n ≥ 0}

Solution: Choose anbn from the first copy of L and ambm from the second. The nonnegative integers n and m are independent.

L2 = {anbnambm | n, m ≥ 0}.

Examples: ε, ab, aabb, aaabbb, abab, abaabb, aabbab, aabbaabb, ….

Taking n = 0 or m = 0 shows that L ⊆ L2 here. Also, abab ∈ L2 but abab ∉ L, so L2 ≠ L.

Remember: L2 pairs every string with every string; it does not require concatenating a string only with itself.

1.19 Kleene Star

The Kleene star (or star closure / Kleene closure) of a language L contains all strings obtained by concatenating zero or more strings from L. Repetition is allowed, and each concatenation uses finitely many factors.

L* = L0 ∪ L1 ∪ L2 ∪ … = ⋃i ≥ 0 Li
Because L0 = {ε}, ε ∈ L* for every language L.

Example: L = {a, ab}

PowerStrings
L0{ε}
L1{a, ab}
L2{aa, aab, aba, abab}
L3{aaa, aaab, aaba, aabab, abaa, abaab, ababa, ababab}

L* is the union of these sets and all higher powers. Examples in L4 include aaaa = a · a · a · a, aabaa = a · ab · a · a, and ababaab = ab · ab · a · ab.

A power counts factors, not symbols. For example, ab · a · a · ab = abaaab ∈ L4, although its length is 6. To prove membership, split the entire string into blocks that each belong to L.

1.20 Positive Closure

The positive closure of L, denoted by L+, contains strings formed by concatenating one or more strings from L.

L+ = L1 ∪ L2 ∪ L3 ∪ …
Therefore L* = {ε} ∪ L+.

Important: “one or more” counts factors, not symbols. If ε ∈ L, then ε ∈ L+ too. Thus L+ = L* − {ε} only when ε ∉ L.

Special cases: ∅* = {ε}, ∅+ = ∅, and {ε}* = {ε}+ = {ε}.

1.21 When Is L* Infinite?

Is L* infinite for every language L? No. There are two exceptions: L = ∅ and L = {ε}.

Case 1: L = ∅

The zeroth power is ∅0 = {ε}, while every positive power is ∅. Hence:

∅* = {ε} ∪ ∅ ∪ ∅ ∪ … = {ε}.

Case 2: L = {ε}

Every power equals {ε}, because concatenating copies of the empty string still gives the empty string.

{ε}* = {ε} ∪ {ε} ∪ … = {ε}.

All Other Languages

If L ≠ ∅ and L ≠ {ε}, then L contains a nonempty string w, with |w| ≥ 1. The strings ε, w, w2, w3, … all belong to L*.

Their lengths are 0, |w|, 2|w|, 3|w|, …, so they are all distinct. Therefore L* is infinite.

L* is finite ⇔ L ⊆ {ε}.
Equivalently, L* is infinite ⇔ L contains at least one nonempty string. In either finite case, L* has exactly one member: ε.

Q9. GATE CSE 2013, Q8: Empty Language and Star

Let L1 = ∅ and L2 = {a}. Which language is represented by L1L2* ∪ L1*?

  1. {ε}
  2. ∅
  3. a* (all strings consisting only of a, including ε)
  4. {ε, a}

Solution: L1L2* = ∅L2* = ∅, while L1* = ∅* = {ε}.

∅ ∪ {ε} = {ε}. Answer: A.

Throughout these examples, let Σ = {a, b}. Recall that Σ* contains every finite string over a and b, while L* uses only concatenations of strings from L.

1.23 Complement of a Language

For a language L ⊆ Σ*, its complement, written L̅, contains every string over the given alphabet Σ that does not belong to L.

L̅ = Σ* − L = {w ∈ Σ* | w ∉ L}.

The alphabet determines the universe: complement is taken relative to Σ*, so specifying Σ matters.

Q10. Complement of L = {an | n ≥ 0} over Σ = {a, b}

Solution: L = {ε, a, aa, aaa, …} contains exactly the strings with no b. Any string over {a, b} outside L must therefore contain at least one b.

L̅ = {w ∈ {a, b}* | w contains at least one b}.

Examples in the complement: b, ab, ba, bb, aab, baba.
Not in the complement: ε, a, aa, aaa, ….

If the alphabet were instead Σ = {a}, the same L would equal Σ*, and its complement would be ∅.

Complement of Equal a and b Blocks

Over Σ = {a, b}, let L = {anbn | n ≥ 0} = {ε, ab, aabb, aaabbb, …}.

A string outside L either has all its a symbols before all its b symbols but has unequal block lengths, or violates that order by containing the substring ba.

L̅ = {anbm | n, m ≥ 0 and n ≠ m} ∪ {w ∈ {a, b}* | w contains the substring ba}.

Examples: aab and abb belong to the first set; ba and abab belong to the second. The empty string is not in the complement, since ε ∈ L.

Q11. Important: Which Star and Positive-Closure Identities Are Always True?

Let L be a language over Σ, and let ε denote the empty string. Select all statements that are always true.

  1. Σ* − {ε} = Σ+
  2. L* − {ε} = L+
  3. Σ* = Σ+ ∪ {ε}
  4. L* = L+ ∪ {ε}

Counterexample for B: L = {ε, a}

Here, L* = {ε, a, aa, aaa, …}. Also, L+ = {ε, a, aa, aaa, …}, because one or more factors from L may include ε itself.

L* − {ε} = {a, aa, aaa, …}, but ε ∈ L+.
The two sides differ, so B is not always true.

Why the Other Options Are Correct

  • A is true: Σ+ contains exactly the nonempty strings over Σ. Alphabet symbols have length 1, so concatenating one or more symbols cannot produce ε.
  • C is true: every string over Σ is either nonempty (in Σ+) or is ε.
  • D is true: L* = L0 ∪ L1 ∪ … = {ε} ∪ L+. This remains true even when ε already belongs to L+, since sets do not count duplicates.

Answer: A, C, and D.
Key condition: L* − {ε} = L+ holds exactly when ε ∉ L. In contrast, L* = L+ ∪ {ε} holds for every language.
