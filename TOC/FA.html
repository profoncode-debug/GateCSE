Introduction to Finite Automata

1.1 Automaton

A finite automaton (FA) is a machine with a finite set of states that processes an input string using transitions between states.

  • States: represent the possible configurations of the machine.
  • Start / initial state: the state where processing begins, often denoted by q0.
  • Accepting / final states: states used to determine acceptance after the entire input has been read.
  • Transitions: specify how the machine changes state on reading an input symbol.

Terminology: “automaton” is singular; “automata” is plural. A final state is an accepting state, not necessarily a state with no outgoing transitions.

1.3 String Acceptance

Begin at the initial state and process the input string w according to the transitions. For a deterministic run, check the state reached after reading the entire input:

State after the Entire InputDecision
Accepting / final stateAccept w
Nonaccepting / nonfinal stateReject w

Read the whole string: reaching a final state partway through the input does not by itself imply acceptance. Continue processing any remaining symbols before deciding.

If a machine allows multiple possible runs, acceptance requires at least one run that consumes the entire input and ends in an accepting state.

Example: Accepting an Odd Number of 1's

Let Σ = {0, 1} and F = {q1}. The DFA below stays in the same state on 0 and switches states on 1. State q0 represents an even number of 1's so far; q1 represents an odd number.

Rejected example, w = 0011:
q0 →0 q0 →0 q0 →1 q1 →1 q0.

Although the run visits q1, the last 1 takes it back to nonfinal q0, so the string is rejected.

Accepted example, w = 0010011:
q0 →0 q0 →0 q0 →1 q1 →0 q1 →0 q1 →1 q0 →1 q1.

The complete string leaves the machine in final state q1, so 0010011 is accepted.

1.4 Language of a Finite Automaton

The language of a finite automaton M, denoted by L(M), is the set of all and only those strings accepted by M.

L(M) = {w ∈ Σ* | M accepts w}.

  • If w ∈ L(M), then M accepts w.
  • If w ∉ L(M), then M rejects w.

Distinguish: acceptance is a decision about one input string; L(M) collects every accepted string into a language.

1.5 Input Tape Working

  • The input tape is divided into cells. Each occupied cell contains one symbol from the input alphabet Σ.
  • The symbols of the input string are placed in consecutive cells, in their original order.
  • The FA reads / scans / consumes the input one symbol at a time, from left to right.
  • Consuming a symbol advances to the next cell on the right, while the transition determines the next state.

ε is not written in an input cell: the empty string has no symbols to place on the tape. An ε-transition, when allowed, changes state without consuming an input symbol or advancing the input position.

1.6 Regular Languages

A language is regular if it is recognized by some finite automaton.

L is regular ⇔ there exists a finite automaton M such that L(M) = L.
M must accept all and only the strings in L.

Example: the binary DFA in 1.3 accepts exactly the strings with an odd number of 1's. Therefore {w ∈ {0, 1}* | w has an odd number of 1's} is a regular language.

1.7 DFA and NFA

Finite automata have two main forms:

  • DFA — Deterministic Finite Automaton: for each state and input symbol, there is exactly one next state.
  • NFA — Nondeterministic Finite Automaton: for a state and input symbol, there may be zero, one, or several next states.

The key difference is the transition function: a DFA returns one state; an NFA returns a set of possible states. Both use finite states, initial and accepting states, and the same definition of the language recognized.

Acceptance: a DFA has one run for an input string. An NFA accepts if at least one possible run consumes the entire input and ends in a final state; it rejects if none does. Both recognize exactly the regular languages.
